# Image guide: decksmith-demo.pptx

Pixel sizes are exact for the frame each picture fills. 1080p = the deck shown 1920 x 1080 (144 px per slide inch); 4K = 3840 x 2160. Source photos should meet the 4K size so they stay sharp on large screens and survive a crop.

## hero

- **Topic:** Night traffic drawn as light trails on a curved city road
- **Pexels query:** `light trails long exposure`
- **Source must be at least:** 1536 x 2160 px

Used in more than one frame: download **one** file at the largest size and place it in every frame (place() crops it). Morph only blends a picture smoothly into the same picture.
